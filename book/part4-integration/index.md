# 第四部分：集成与模式

> 多端共享、三层扩展、十大模式：从工程实现到方法论提炼。

Agent 不是孤岛——它需要与 IDE、Web、移动端对接，需要用户和开发者扩展它的能力，需要把经验提炼为可复用的模式。

**第 10 章** Bridge 与协议层：NDJSON 双向协议、三代传输演进（WebSocket → Hybrid → SSE+CCR）、UUID 去重、权限委托——让多端共享一个 Agent 实例。

**第 11 章** 三层扩展谱系：Skill（提示模板定义工作流）、Plugin（MCP 协议引入外部能力）、Hook（26 种事件 × 4 种执行后端注入行为逻辑）。

**第 12 章** 全系列回顾，从 512K 行代码中提炼 10 个可复用的 Agent 工程模式——从自愈主循环到编排-执行分离，从投机执行到传输无关协议。
