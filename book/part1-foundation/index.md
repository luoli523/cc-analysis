# 第一部分：架构基础

> 从全景到细节：技术栈选型、ReAct 主循环设计、Token 经济学与缓存策略。

Claude Code 是一个藏在终端里的 AI Agent 运行时——512K 行 TypeScript、1,900 个文件。这一部分从宏观到微观，建立对整个系统的认知框架。

**第 1 章** 给出全景导读：技术栈为什么选 Bun + React + Yoga？核心数据流如何从用户输入到终端渲染？

**第 2 章** 深入 Agent 的心脏——`while(true)` 主循环。五个阶段、两种工具执行模式、七层错误恢复机制，让 Agent 在各种异常下都能自我修复。

**第 3 章** 解决 Token 经济学问题：如何通过缓存分割让输入成本降低 10 倍？对话增长时，四级压缩如何保留核心信息？
